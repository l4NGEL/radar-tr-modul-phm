# Kavramlar

| Terim | Anlami |
|---|---|
| **BIT** (Built-In Test) | Sistemin kendi kendine, calisirken veya periyodik olarak saglik durumunu kontrol etmesi |
| **CIT** | Hata teshisi/lokalizasyonu icin gereken test edilebilirlik tasarimi -- "hangi olcum hangi arizayi ayirt ediyor" sorusunun cevabi |
| **FMEA** (Failure Mode and Effects Analysis) | Her bilesen icin olasi ariza modlarini, nedenlerini, etkilerini ve tespit yontemlerini sistematik listeleyen analiz |
| **FDC** (Fault Detection Coverage) | Gercek arizalarin yuzde kaci basariyla tespit edildi |
| **FAR** (False Alarm Rate) | Gercekten saglikli orneklerin yuzde kaci yanlislikla "ariza" olarak isaretlendi |
| **Fault Isolation** | Tespit edilen bir arizanin HANGI bilesene/moda ait oldugunun belirlenmesi (lokalizasyon) |
| **MTTD** (Mean Time To Detect) | Gercek ariza baslangicindan ilk dogru tespite kadar gecen ortalama sure |
| **RUL** (Remaining Useful Life) | Bir bilesenin kritik/arizali esige ulasmasina kalan tahmini sure -- kestirimci bakimin temeli |
